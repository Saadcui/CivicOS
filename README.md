# CivicOS

Tools and validation reports for an AI-based city-surveillance road-condition
dataset.

## What is included

- Dataset inspection and label-fixing scripts
- Validation report
- A small representative sample in [`samples/`](samples/)

The complete image and label dataset is intentionally not included in this
repository. It is available from the original source:

<https://zenodo.org/records/18871460>

## Dataset classes

- Cracks
- Good road
- Open manhole
- Pothole
- Waste container

## Usage

Create a Python environment, install the dependencies required by the scripts,
then update the dataset path in the scripts before running them.
